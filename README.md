# The Confetti Way — Concierge

Responsive concierge website preview for The Confetti Way, Harbor Country, Michigan.

Published with GitHub Pages from the root of the main branch. Open index.html locally to preview; all images and fonts are included.

The enquiry planner prepares an email draft for the visitor to review and send. It does not confirm availability, reserve bookings, or take payments.

Brand artwork and most imagery are retained from the client website for the authorized redesign. Asset origins are recorded in assets/sources.json. The illustrative Lake Michigan stock image is credited there; it is not represented as a verified client portfolio photograph. Font licenses are included with the assets.
